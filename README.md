**Areas of development, with several tasks solved**

1. Themes
2. Responsive support in `.css`
3. Emails Rendering Quality
4. Command Line Shell `bash`
5. Optimization

     * HTML templates transparency ( Template Renderer for JSON Rendering Tools, TreeWalker base methods )
     * Optimization for DOM Interactivity ( Improved Renderer Event Emitter )
     * RAM for DOM ( thin optimized html template renderer, optimized event listener )
     * Traffic, requests number minimization ( Workarounds for CDN and Preloading )
     * Public repositories storage space ( Workarounds for CDN, Webpack and Media storing repos )
     * Parsing ( ObjData )
